# Syphon Filter: The Omega Strain (PC port) - port settings.
# Port-only settings: none of these exist in the PS2 game, and none of them change the game's own options

# Port Settings page (title Options > Control > PORT SETTINGS, or the pause menu's last entry) changes them too.

# Present on the display's vertical blank (also: Options > Video > VSYNC). The game's 60 Hz step is the same either way.

# window_units=pixels
